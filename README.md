# 💜 JD: A Little Universe

*A little universe, coded by a fan.* ✨

JD: A Little Universe is an interactive fan-made website inspired by Joong Archen and Dunk Natachai. This project combines my love for Thai BL dramas and frontend web development to create a fun, cosmic-themed digital experience.

## 🌌 Features

- ✨ Animated starry background
- 💜 Interactive message cards
- 🌙 Beautiful purple-and-black cosmic theme
- 🎮 Mini quiz for fans
- 📱 Responsive design for different screen sizes
- 💻 Beginner-friendly frontend code

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 Live Demo

[Visit JD: A Little Universe](https://ekta918.github.io/JD-a-little-universe/)

## 💻 Run Locally

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Explore the interactive features!

## 🎯 Purpose

This project is a personal creative coding project built to practice frontend development, explore interactive UI design, and connect coding with my interest in Thai BL fandom.
